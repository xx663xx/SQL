# База данных автосалона

В проекте собрана база данных для автосалона и простое графическое приложение на Tkinter, через которое можно смотреть таблицы, добавлять записи, оформлять продажи, бронировать автомобили, записывать тест-драйвы и открывать готовые отчеты.

Сценарий простой. Есть машины, клиенты, сотрудники, продажи, бронирования, тест-драйвы, сервисные заявки и поставщики. Все это связано внешними ключами, поэтому данные не лежат отдельными несвязанными списками.

## Как запустить

Нужен Python 3. Дополнительные библиотеки ставить не требуется, приложение использует стандартные модули `tkinter` и `sqlite3`.

```bash
python3 main.py
```

При запуске программа подключается к базе `data/dealership.db`. Если нужно пересоздать структуру и демонстрационные данные, за это отвечает инициализация из файлов `sql/schema.sql` и `sql/seed_data.sql`.

## Что внутри

Основное окно находится в `main.py`. Папка `app` хранит логику работы с базой, таблицами, отчетами и договорами. SQL-файлы лежат отдельно в `sql`, чтобы структуру базы и запросы было легко проверить без запуска интерфейса.

В `docs` лежат отчеты по проекту, а в `screenshots` собраны изображения интерфейса, ERD и IDEF0-диаграмм. Шаблон договора хранится в `templates`, готовые договоры сохраняются в `contracts`.

## Что можно делать в приложении

Через интерфейс можно открыть справочники автомобилей, клиентов, сотрудников и поставщиков. Отдельно доступны продажи, брони, тест-драйвы и сервисные заявки. Для продаж есть формирование договора по шаблону, а в разделе отчетов собраны SQL-запросы для проверки данных и простого анализа.
